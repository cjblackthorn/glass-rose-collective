# Glass Rose Collective

Glass Rose Collective is an indie artist publishing, representation, and creative support collective focused on helping creators grow without losing themselves in the process.

## Mission

Support independent creators through:

- publishing support
- artist representation guidance
- branding and identity
- collaboration
- referrals and networking
- community-focused creative development

## Tech Stack

- GitHub Pages
- Jekyll
- Custom styling layer

## Planned Features

- Featured artist pages
- Submission system
- Creator showcases
- Community integrations
- Multimedia publishing support
- Collaborative releases
- SEO optimization
- Artist resources

## Branding

Visual identity centers around stained-glass-inspired imagery representing individuality, resilience, and collective creativity.
